Rate My Prompt

A playful protocol that lets an AI generate a Markdown "prompting report card."

Protocol

Raw (curl-friendly):

https://raw.githubusercontent.com/davidlrnt/rate-my-prompt/main/protocols/prompt-relationship-report-v1.md

Tip: open it in your browser to preview the instructions.

How to use

  1. Get the protocol (choose one option below).
  2. Give it to your agent along with the conversation excerpt you want reviewed.
  3. The agent returns a Markdown report card.

Option A (recommended): Fetch protocol via CLI

Run this locally to print the protocol, then paste it into your agent:

curl -L https://raw.githubusercontent.com/davidlrnt/rate-my-prompt/main/protocols/prompt-relationship-report-v1.md

Option B: Agent can fetch URLs (if browsing/tools are enabled)

Paste this into your agent:

Fetch and follow this protocol exactly:
https://raw.githubusercontent.com/davidlrnt/rate-my-prompt/main/protocols/prompt-relationship-report-v1.md

Conversation excerpt:
<paste here>

Option C: No browsing/tools available (copy/paste protocol)

If the agent cannot fetch URLs, paste the protocol text directly:

PROTOCOL (paste this entire block first):
<paste the contents of prompt-relationship-report-v1.md here>

Conversation excerpt:
<paste here>
No backend. Just Markdown. GitHub
